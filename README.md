# StudyCircle

A web app that helps university students create and manage study groups for specific courses.

## Team Members
- Diego Artemio García
- Joshua Abinadi Cirilo
- Taiye Gabriel Ade‑Benson
- Nelson Mandella Akpomah

## Project Setup
- Built with Next.js (TypeScript, Tailwind CSS, App Router)
- ESLint configured for code quality
- GitHub repository initialized with protected `main` branch

## Purpose
StudyCircle allows students to:
- Create study groups for specific courses
- Join existing groups
- Schedule and share meetings
- Collaborate effectively with peers
